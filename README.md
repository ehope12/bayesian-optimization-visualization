# bayesian-optimization-visualization

A script for visualizing the process of Bayesian optimization.

## Getting Started

### Dependencies

* Python
* Numpy
* Sklearn
* Scipy
* Matplotlib

### Usage

Once you have all of the listed dependencies, clone the repo. Then run the Python script:
```
python bayesian_optimization_visualization.py
```

Adjust the acquisition function by changing which method is commented out (or add a new one). Adjust the blackbox function at the top of the file. Adjust the number of iterations -- and thus the number of visualizations -- by changing the num_iterations variable.
